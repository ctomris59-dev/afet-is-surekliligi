# Afet & İş Sürekliliği Skorkartı — Üye Dönüşüm Portalı

Bu sürüm, Çorlu TSO Üye Dönüşüm Portalı tasarım ailesi ve Dijital Olgunluk uygulamasıyla uyumlu olacak şekilde yeniden tasarlanmıştır.

- Manrope + DM Sans tipografi
- Kurumsal lacivert + afet/kritik durum kırmızısı
- 100dvh tam ekran, ana sayfalarda scroll yok
- Giriş, 18 soruluk değerlendirme, iletişim ve sekmeli sonuç ekranları
- Scrollsuz metodoloji ve KVKK modalları
- Supabase kayıt ve PDF raporu korunmuştur

Kontrol marker: `UI-FIX-BCM-2026-08-21-FULLSCREEN-PORTAL-V1`
